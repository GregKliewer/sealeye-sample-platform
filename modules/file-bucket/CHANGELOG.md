# Changelog: file-bucket

Released as `file-bucket/v<version>` tags. A major version changes what the module takes or gives; read its entry before moving an app to it.

## 1.1.0

- Offers what an app needs to use the bucket as outputs: `access_policy_arn` (reads, writes and deletes files) and `read_only_policy_arn`.

## 1.0.0

- The module as the platform team first published it.
